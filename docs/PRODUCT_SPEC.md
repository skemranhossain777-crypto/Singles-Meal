
# Singles Meal — Product Specification

## Roles
- Customer: browse menu, manage profile/preferences/allergies, order, subscribe, track orders, log meals.
- Admin: manage catalog, pricing, roles, refunds, reporting, kitchen and delivery.
- Kitchen: view confirmed production batches, ingredient/allergen sheets, update preparation status.
- Rider: view assigned deliveries and update delivery state.

## Customer journeys
1. Discover menu → view nutrition/ingredients/allergens → add to basket → sign in → choose delivery address/slot → create pending-payment order → verified provider webhook marks payment paid → order confirmed.
2. Onboarding → consent → food goal/preferences/allergies → recommended catalog filtered by hard allergy exclusions → select meals.
3. Select subscription → schedule and delivery address → admin confirms capacity and payment → subscription active → scheduled orders generated by trusted server job.

## Nutrition rules
- Store nutrition per serving, sourced from ingredient weights and a maintained recipe.
- Recalculate when recipe or portion changes.
- Display estimated values and serving size.
- Allergy exclusions must be enforced server-side and in kitchen SOPs.
- Do not present calorie estimates as clinical advice or promise weight outcomes.

## Operational states
Order: pending_payment → confirmed → preparing → ready_for_pickup → out_for_delivery → delivered.
Exception states: cancelled, refunded.
Only trusted server-side payment webhook may transition an order from pending_payment to confirmed.
Kitchen staff can move confirmed → preparing → ready_for_pickup.
Rider/admin can move ready_for_pickup → out_for_delivery → delivered.

## Not yet production-complete
- Provider-specific payment initiation and signed webhooks.
- Subscription billing scheduler and recurring order generation.
- Delivery rider assignment and live map.
- Inventory deduction / lot and expiry traceability.
- Full admin CRUD and granular audit logs.
- SMS/OTP provider setup and push notification service.
- Formal security review, privacy policy, food safety and legal review.
